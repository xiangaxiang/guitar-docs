D15吉他使用指南

连上吉他，选一首歌，开始弹奏。

快速上手更多玩法常见问题

安装 App：iPhone / iPad · Android，首次打开允许蓝牙和联网。

1连接吉他

有电源开关的吉他，向上拨动开机；没有开关的，接通 5V USB 电源。下面两种连接方式选一种即可。

蓝牙

在 App 右上角打开「连接吉他」，选「蓝牙」，找到 D15Guitar 并连接。

USB

用 USB 数据线连接吉他和手机，在「连接吉他」里选「USB」。

显示「可以演奏」后，就连好了。

水果套件：接线与上电

将线的一端接到开发板对应的 IO，另一端接水果或果冻。下表按开发板的 IO 标号接线，不是从上往下数第几个针脚。

功能IO默认 C 组
和弦键 1 / 2 / 3 / 42 / 12 / 11 / 10C / Dm / Em / F
和弦键 5 / 6 / 7 / 85 / 6 / 7 / 9G / Am / Bdim / G7
扫弦 / 分解1 / 4按所选和弦演奏

接好后，手离开材料，再接通 USB 电源，等待约 2 秒。随后按上面的蓝牙方式连接 App，触摸材料即可演奏，声音由手机播放。

更换材料或接线后，松手重新上电。智能谱和自定义和弦会改变各键的和弦，请以 App 提示为准。

USB 需要支持数据传输的线。最早 HW1 仅支持蓝牙演奏；线材、转接器等问题见下方常见问题。

2选择歌曲

进入「智能谱」，在「曲库」中搜索歌名或歌手，点开歌曲即可下载并打开。也可以从「收藏」或「最近」找到常弹的歌。

下载新歌需要联网；已经下载的歌曲可以离线弹奏。

3开始跟弹

进入「智能谱」选歌，按谱面提示按下对应的和弦键。有灯光版还可跟着按键灯弹奏。

有喇叭的吉他进入智能谱后自动静音，由手机发声，退出后恢复。

查看按键对照

吉他竖拿，从上往下看。默认 C 和弦组的按键如下；切换和弦组、移调或跟弹歌曲后，请以 App 谱面提示为准。

更多玩法

自由弹奏：一键、双手与单音

不打开歌曲，也可以按自己的节奏演奏。在控制页「演奏设置」中选择分解 / 扫弦、节奏型、BPM、移调和演奏模式。

模式怎么弹
一键弹奏按和弦键触发演奏，按当前选择的分解或扫弦节奏播放。
双手弹奏左手选和弦，右手按分解键或扫弦键触发。
单音八个和弦键分别演奏单个音符，适合弹旋律。

有灯光版开机后可直接独立演奏；无灯光版需要连接手机或电脑发声。

智能谱：弹法、伴奏与谱面设置

两种吉他弹法

  • 精准原谱：歌曲包含原谱吉他轨时，按原谱音符和节奏演奏。
  • 自选节奏型：使用自己选择的分解 / 扫弦和节奏型配合歌曲。

BPM 和移调在两种弹法下都可调；分解 / 扫弦、节奏型只用于自选节奏型。演奏模式可独立选择一键弹奏或双手弹奏。

常用操作

  • 伴奏：顶部快捷键开关伴奏；在设置中分别调整主旋律、吉他、节拍器和鼓机等音量。
  • 和弦名称：切换字母或数字显示；数字只显示根音，C、D、E、F、G、A、B 对应 1–7。也可点谱面上的和弦名称切换。
  • 谱面：顶部快捷键循环切换三种谱面显示；设置中可调整谱面大小。
  • 跳过前奏：从顶部快捷键跳到可开始跟弹的位置。
  • 自动播放：可先听整首歌曲，再切回吉他跟弹练习。

拖动时间线可调整练习位置。演奏结束后退出谱面，会停止本次歌曲播放。

找歌、下载和管理

搜索支持歌名、歌手、拼音和拼音首字母。点开在线歌曲时才下载曲谱；再次打开未更新的已下载歌曲会使用本机文件。

首次使用在线曲库时，先联网连接并验证配套设备。取得资格后，不需要每次下载都连接设备。

曲库右上角的「…」菜单可刷新列表、仅显示已下载的歌曲，或导入自己的曲谱文件。「管理已保存的曲谱」只整理本机文件，不会删除网上的歌曲。

升级 App 会保留已有歌曲、收藏和最近记录。与在线曲库不重复的个人导入歌曲仍保留在列表中；重要的自编歌曲请另存备份。

不同版本曲谱格式可能不同；旧曲谱或自行制作的文件应按当前导入入口支持的格式使用。

平滑衔接与吉他本地声音

「弹奏 → 其他」中可查看平滑衔接等较少使用的选项。平滑衔接用于在相邻演奏段之间自然连接，具体触发方式随演奏模式变化。

有喇叭的吉他默认在智能谱中静音。需要同时发声时，可在「弹奏 → 其他 → 吉他本地声音」手动开启；吉他本地演奏与手机原谱声音可能不一致。

自定义和弦与和弦组
  1. 在控制页「演奏设置 → 和弦组」中选择 C 组、G 组或自定义组。
  2. 在「自定义按键」编辑八个按键的和弦，也可先复制 C 组或 G 组。
  3. 连接吉他后点「同步到吉他」；需要读取琴中已有配置时点「从吉他读取」。

连接时如提示有修改待同步，选「使用吉他设置」或「使用 App 设置」，决定以哪一端为准。

吉他上的组合快捷键

同时按住最下面的分解键（10）和扫弦键（9），再按下表中的和弦键。完成后松开组合键，恢复演奏。

再按哪个键功能
1 / 2移调升 / 降一个半音
1 + 2移调归零
3切换和弦组
5 / 6BPM 加 / 减；按住可连续调节
5 + 6BPM 恢复 75
7切换节奏型
8循环切换一键弹奏 / 双手弹奏 / 单音

这些是自由弹奏的琴上快捷键。智能谱中的歌曲速度、音调和弹法，请在歌曲设置里调整。

手机音色与尾音

在控制页「手机声音」选择音源和音色。内置「吉他专用」主要提供吉他音色，「通用乐器」供多种乐器使用；伴奏按歌曲的轨道选择对应音色。

「手机尾音」A 保留自然余音，B 按节奏收尾；精准原谱按音符时值播放。带音色菜单的吉他可使用「跟随吉他音色」，让手机在自由弹奏时跟随吉他选择的乐器。

吉他声音、灯光与音色菜单（有灯光版）
  • 开机：电源开关向上拨，按任意和弦键即可独立弹奏。
  • 充电：用 USB 线接 5V USB 电源，充电时指示灯亮，充满后熄灭。
  • 音量：短按音量键，在 1–4 档与静音之间循环。
  • App 调节：连接后可调整吉他音量档位、尾音、混响，以及按键灯、待机灯和开机提示。

音量档位和混响等调节可即时试听，需长期保留时按页面上的「保存到吉他」或「保存档位设置」。标为自动保存的灯光、开机提示设置会自动保存。手机与吉他音量分别控制。

选择吉他上的音色

长按音量键约 1 秒打开菜单。按亮着的键选择；进入吉他组后先松键，再选具体音色。选择后松键，再开始演奏。菜单约 10 秒未操作会退出，保留原音色。

长按音量键可返回一级音色菜单。

连接库乐队等 MIDI 软件

D15吉他也可作为 MIDI 控制器使用，声音由库乐队等软件的乐器轨道产生。第三方软件不会提供 D15 App 的智能谱、设备设置等功能。

Mac / iPhone / iPad 的库乐队

Mac 蓝牙：打开「音频 MIDI 设置 → 窗口 → 显示 MIDI 工作室 → 配置蓝牙」，连接吉他；再在库乐队选择软件乐器轨道。

Mac USB：支持 USB MIDI 的吉他接入后，在库乐队选择软件乐器轨道。不要同时接通同一把琴的蓝牙 MIDI 输入。

iPhone / iPad：在库乐队的设置中找到「高级 → 蓝牙 MIDI 设备」并连接，然后打开一个触控乐器；支持 USB MIDI 的吉他也可通过合适的数据线或转接器使用。

Apple 操作说明：Mac 蓝牙 MIDI / iPhone 库乐队。

其他手机或电脑 MIDI 软件

先确认软件支持 USB MIDI 或 BLE MIDI，然后在它的 MIDI 输入设置中选择吉他，并加载可发声的乐器。不同软件的蓝牙入口可能不同；不能只在系统蓝牙里配对后就认为已经接通 MIDI。

固件更新

已是 5.x：在手机上更新

  1. 让吉他与手机通过蓝牙连接，并保证电量充足。
  2. 打开「连接吉他 → 设备信息与更新 → 固件更新」。检查更新不会立即刷写吉他。
  3. 发现新版后，点「下载并升级」，等待传输完成和吉他自动重启。

App 在线升级目前仅支持蓝牙。USB 可以供电；无需按 BOOT / RESET。升级过程中保持连接，不要关闭吉他或退出 App。

如提示超时，先重新连接并查看当前版本，再决定是否重试。

4.5 等旧固件：先用电脑升级

旧固件不能直接使用 App 的在线升级流程。需使用电脑和 ESP Tool，按吉他型号选择对应的手动升级包及随包说明；不要混刷其他型号。

升级到配套 5.x 固件后，即可使用新版 App 和后续蓝牙升级。需要升级包或不确定型号时，请联系售后。

常见问题

仍在使用 App 2.0，怎么导入歌曲？

首次连接设备后，回到主界面，按提示下载并导入歌曲。也可从「智能谱 → 导入歌曲 → 从网络导入歌曲」进入。2.1 使用在线曲库，点开歌曲时下载，无需先导入整包。

USB 线和转接器怎么选？

使用支持数据传输的线；仅充电线不能连接 MIDI。USB-C 手机可用合适的数据线；Lightning 接口需要支持 USB 外设的转接器。Android 转接器需支持 OTG，部分手机需在系统设置里开启 OTG。

最早 HW1 的 USB 仅用于供电和电脑刷机，演奏请选蓝牙。其他无灯光款和有灯光款按实际支持的连接方式使用。

扫描不到吉他

检查吉他电源、手机蓝牙和 App 蓝牙权限。断开其他手机、电脑上的连接，再回到 App 扫描；旧名称设备可尝试关闭名称过滤。

提示暂时无法使用、验证失败或需要升级

先断开重连。若仍失败，核对固件版本；旧固件需先用电脑更新。不要因此删除 App 或清空歌曲。联系售后时提供页面提示、设备型号和 MAC 地址。

连上但没有声音，或声音重复

确认已经显示「可以演奏」，检查手机媒体音量、静音状态和音频输出是否去了耳机。第三方软件还需选中可发声的乐器轨道。重复发声时，先确认没有同时启用 USB 和蓝牙两路 MIDI。
