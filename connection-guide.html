D15吉他 连接说明

App 2.0 · 固件 5.x · 2026-10-16 更新

本页用于 D15吉他 App 2.0 与固件 5.x。有灯光版和无灯光版共用 App，声音、灯光功能按吉他支持情况显示。

仍使用旧 App 或 4.5 等旧固件？请看 Legacy 旧版说明。旧款吉他升级到 5.x 后，按本页操作。

先选一种连接方式

USB / 蓝牙，选择一种即可。在 App 右上角打开「连接吉他」，选择对应方式。

有灯光版

带按键灯、喇叭和内置电池。将电源开关向上拨，开机后可独立弹奏，也可连接手机。

无灯光版

连接手机或电脑发声。蓝牙演奏时，用 USB 接通 5V 电源；支持 USB MIDI 的款式也可用数据线直接连接手机。

最早的 HW1 仅支持蓝牙 MIDI，USB 用于供电和电脑刷机；HW2、HW3 及有灯光版支持 USB MIDI。无法确定型号时，可联系售后核对。

安装 iPhone / iPad 版 或 Android 版。首次打开允许蓝牙和联网；Android 如提示「附近的设备」权限，也需允许。

蓝牙连接

  1. 给吉他开机或接通电源，打开手机蓝牙。
  2. 在 D15吉他 App 右上角打开「连接吉他」，选择「蓝牙」。
  3. 扫描并选择 D15Guitar，等待显示「可以演奏」。

在 App 内连接即可，不必先在手机系统设置里配对。启用「自动连接上次蓝牙设备」后，下次打开 App 会尝试重连。

旧固件可能显示旧蓝牙名称；找不到时可关闭连接页的设备名称过滤，或查看 Legacy 说明。吉他若已连着另一部手机或电脑，先从另一端断开。

USB 连接

  1. 使用支持数据传输的 USB 线，将吉他连接手机。只有充电功能的线无法传输 MIDI。
  2. 在 App「连接吉他」中选择「USB」。出现系统 USB 权限提示时允许，等待「可以演奏」。

USB-C 手机可使用合适的数据线；Lightning 接口的 iPhone / iPad 需要支持 USB 外设的转接器。Android 转接器需支持 OTG，部分手机还需在系统设置里开启 OTG。

如果同时接着 USB 又连着蓝牙，只选一条演奏路径。使用第三方 MIDI 软件时尤其要避免同时启用同一把吉他的两路输入，否则可能重复发声。

连上以后

  1. 导入歌曲：首次连接后按提示下载并导入；选择「稍后」也可从「智能谱 → 导入歌曲 → 从网络导入歌曲」进入。下载需要联网。
  2. 开始跟弹：在智能谱中选歌，按谱面提示弹奏。有灯光版还会给出按键灯提示。
  3. 查看设备：「连接吉他 → 设备信息与更新」里可查看型号、MAC 地址、固件版本。

这台手机取得下载资格后，后续下载歌曲不必一直连接吉他。同编号歌曲会更新，其余歌曲保留。

进入智能谱时，有喇叭的吉他默认静音，手机发声，退出后恢复。更多玩法见使用说明。

固件更新

已是 5.x：在手机上更新
  1. 让吉他与手机通过蓝牙连接，并保证电量充足。
  2. 打开「连接吉他 → 设备信息与更新 → 固件更新」。检查更新不会立即刷写吉他。
  3. 发现新版后，点「下载并升级」，等待传输完成和吉他自动重启。

App 在线升级目前仅支持蓝牙。USB 可以供电；无需按 BOOT / RESET。升级过程中保持连接，不要关闭吉他或退出 App。

如提示超时，先重新连接并查看当前版本，再决定是否重试。

4.5 等旧固件：先用电脑升级

旧固件不能直接使用 App 的在线升级流程。需使用电脑和 ESP Tool，按吉他型号选择对应的手动升级包及随包说明；不要混刷其他型号。

升级到配套 5.x 固件后，即可使用新版 App 和后续蓝牙升级。需要升级包或不确定型号时，请联系售后。

连接第三方 MIDI 软件

D15吉他也可作为 MIDI 控制器使用，声音由库乐队等软件的乐器轨道产生。第三方软件不会提供 D15 App 的智能谱、设备设置等功能。

Mac / iPhone / iPad 的库乐队

Mac 蓝牙：打开「音频 MIDI 设置 → 窗口 → 显示 MIDI 工作室 → 配置蓝牙」，连接吉他；再在库乐队选择软件乐器轨道。

Mac USB：支持 USB MIDI 的吉他接入后，在库乐队选择软件乐器轨道。不要同时接通同一把琴的蓝牙 MIDI 输入。

iPhone / iPad：在库乐队的设置中找到「高级 → 蓝牙 MIDI 设备」并连接，然后打开一个触控乐器；支持 USB MIDI 的吉他也可通过合适的数据线或转接器使用。

Apple 操作说明：Mac 蓝牙 MIDI / iPhone 库乐队。

其他手机或电脑 MIDI 软件

先确认软件支持 USB MIDI 或 BLE MIDI，然后在它的 MIDI 输入设置中选择吉他，并加载可发声的乐器。不同软件的蓝牙入口可能不同；不能只在系统蓝牙里配对后就认为已经接通 MIDI。

连不上或没有声音

扫描不到吉他

检查吉他电源、手机蓝牙和 App 蓝牙权限。断开其他手机、电脑上的连接，再回到 App 扫描；旧名称设备可尝试关闭名称过滤。

提示暂时无法使用、验证失败或需要升级

先断开重连。若仍失败，核对固件版本；旧固件需先用电脑更新。不要因此删除 App 或清空歌曲。联系售后时提供页面提示、设备型号和 MAC 地址。

连上但没有声音，或声音重复

确认已经显示「可以演奏」，检查手机媒体音量、静音状态和音频输出是否去了耳机。第三方软件还需选中可发声的乐器轨道。重复发声时，先确认没有同时启用 USB 和蓝牙两路 MIDI。
