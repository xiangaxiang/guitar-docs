D15吉他 连接说明

V1 · 请按你的设备选择

iPhone / iPad

准备：苹果应用商店（App Store）下载 "D15吉他" App

推荐：USB(Type-C) 有线连接

  1. 使用支持数据传输的USB线连接吉他与iPhone，吉他红色指示灯亮起。
  2. 打开"D15吉他"App，看到“有线/外设 MIDI 已连接”后即可使用。

USB适用于：吉他硬件V2.0及以上版本，iPhone15及以上版本，低版本请使用蓝牙BLE 无线连接。

其次：蓝牙BLE 无线连接

  1. 将吉他左侧USB接口，接入充电宝或5V电源，吉他红色指示灯亮起
  2. 进入"D15吉他"App"，点右上角蓝牙图标，点“扫描”。
  3. 选择 D15Guitar，连接后回到控制页。

所有版本吉他硬件，均可通过苹果设备 BLE 蓝牙连接。

Android 手机 / 平板

准备：安装安卓版 "D15吉他" 安装包

推荐：USB (Type‑C) 有线连接

  1. 用支持数据传输的USB线连接吉他和安卓设备。
  2. 打开"D15吉他"App，看到“有线/外设 MIDI 已连接”后即可使用。

USB 适用于吉他硬件V2.0及以上；硬件V1.0不支持安卓设备。

其次：蓝牙BLE 无线连接

  1. 将吉他左侧USB接口，接入充电宝或5V电源，吉他红色指示灯亮起
  2. 进入"D15吉他"App"，点右上角蓝牙图标，点“扫描”。
  3. 选择 D15Guitar，连接后回到控制页。

硬件V2.0及以上支持安卓蓝牙BLE连接。

受安卓系统蓝牙影响，蓝牙可能连接不上或演奏可能有延迟，请优先使用有线USB。

D15吉他兼容其他第三方MIDI软件

iPhone / iPad

准备：苹果应用商店（App Store）下载 "库乐队" App

推荐：USB(Type-C) 有线连接

  1. 使用支持数据传输的USB线连接吉他与iPhone，吉他红色指示灯亮起。
  2. 打开"库乐队"App，点右上角+，音轨选择吉他后可直接使用。

USB适用于：吉他硬件V2.0及以上版本，iPhone15及以上版本，低版本请使用蓝牙BLE 无线连接。

其次：蓝牙BLE 无线连接

  1. 将吉他左侧USB接口，接入充电宝或5V电源，吉他红色指示灯亮起
  2. 打开"库乐队"App，点右上角+，音轨选择吉他
  3. 进入后点右上角「设置」（齿轮图标）-> 最下方「高级」-> 最下方「蓝牙 MIDI 设备」，选择 D15Guitar，连接后回到主页。

所有版本吉他硬件，均可通过苹果设备 BLE 蓝牙连接。

Android 手机 / 平板

准备：从应用宝APP下载「随身乐队」。（应用宝：sj.qq.com

推荐：USB (Type‑C) 有线连接

  1. 用支持数据传输的USB线连接吉他和安卓设备。
  2. 打开"随身乐队"App，选吉他后即可使用。

USB 适用于吉他硬件V2.0及以上；硬件V1.0不支持安卓设备。

经本人测试用小米手机+随身乐队，无法使用蓝牙BLE连接，请使用有线USB。

Mac 电脑

推荐：USB(Type-C) 有线连接

  1. 用USB数据线连接吉他和 Mac。
  2. 打开库乐队，选择吉他乐器即可演奏。

USB 适用于硬件 V2.0及以上；硬件 V1.0 不支持 USB。

其次：蓝牙 MIDI

在 macOS“音频 MIDI 设置”中打开蓝牙 MIDI 配置并连接吉他，再打开库乐队。

所有吉他硬件均可通过苹果设备 BLE 蓝牙连接。

Windows 电脑

推荐：USB(Type-C) 有线连接

本人实测 Windows 11 + Cakewalk，可以正常使用。

Windows电脑环境及其复杂，不同电脑、驱动和音乐软件可能存在很大差异。

连接后没有声音？

  • 检查吉他上电源指示红灯是否亮起，没亮请重新插拔。
  • 确认使用的是数据线，不是只能充电的线。
  • 查看 D15 App 连接状态，确认当前走 USB 还是蓝牙。
  • 使用 D15 App 时，检查手机音量和“App 不发声”设置。
  • 使用库乐队、随身乐队或 Cakewalk 时，确认已创建软件乐器音轨并选择音色。
蓝牙搜不到吉他

确认硬件版本支持蓝牙，并检查吉他是否已被另一台设备或其他 App 占用。断开其他连接后重新扫描，必要时重启吉他和蓝牙。
